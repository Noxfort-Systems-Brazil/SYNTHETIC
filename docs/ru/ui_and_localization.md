# 🖥️ Графический интерфейс и динамическая локализация (i18n)

В документе описана архитектура настольного интерфейса **SYNTHETIC** на базе CustomTkinter и TkinterMapView, а также механизм динамической смены языка в реальном времени.

## 1. Архитектура интерфейса

Интерфейс построен на **CustomTkinter** с поддержкой масштабирования High-DPI и темного/светлого оформления:
* Модульная структура разделов (`ui/components/`): выбор карты, типы датчиков, длительность и интенсивность потока, процент отказов и языковое меню.
* Асинхронное выполнение: генерация запускается в фоновом потоке, не блокируя GUI, с передачей событий прогресса через `root.after(0, ...)`.

---

## 2. Интерактивная карта (`ui/map_selector.py`)

Окно **`MapSelectorWindow`** использует библиотеку **`tkintermapview`**:
* Автоматическое центрирование по границам файла `.osm`.
* Размещение датчиков: красные маркеры для камер LPR, синие — для индуктивных петель.
* Контроль квот датчиков в режиме реального времени.

---

## 3. Движок динамической локализации (i18n)

Смена языка интерфейса происходит **на лету без перезапуска приложения Python**:
* Синглтон **`Translator` (`ui/translator.py`)** управляет загрузкой словарей `ui/locale/` (`en`, `pt-br`, `es`, `fr`, `ru`, `zh-cn`).
* Метод `SyntheticApp.update_ui_texts()` мгновенно обновляет все текстовые метки и подсказки.
